# 사업자 고지 변경의 main 기반 QA

2026-09-30, 브랜치 `codex/merchant-site-remediation`. 원격 main에서 분리했으며 미배포 Gumroad/PayApp 추가 변경은 포함하지 않는다.

## 변경

- 공개 표시용 환경설정에서 사업자 고지를 서버 컴포넌트로 렌더링한다. 환경설정 예시에는 빈 키만 추가했다. 실제 값과 인증정보는 커밋하지 않는다.
- 모든 페이지 푸터에서 이용약관·개인정보·환불 정책에 접근할 수 있다. 홈의 브랜드 블록을 유지한다.
- 개인정보 문의 페이지의 가짜 전화번호·잘못된 이메일을 실제 업무 이메일로 정정했다. 전체 정책의 법적 적합성 검토를 대체하지 않는다.

## 확인

- 변경 소스의 Next ESLint: 오류·경고 없음.
- 프로덕션 빌드: 종료 코드 0. 기존 타입/린트 생략 설정·Supabase Edge 경고·API 정적 렌더 경고는 별도로 남아 있으며 전체 기능/결제 QA가 아니다.
- 분리 빌드의 개인정보 페이지: 사업자 고지·정책 링크·잘못된 연락처 제거·가로 넘침 없음.
- 분리 빌드 환불 정책: 정확한 로컬 빌드 URL, 사업자 고지 항목·정책 링크 확인.
- 동일 소스의 기존 작업 공간에서 등록증 번호·주소 일치 여부와 약관/상품/환불 페이지, 모바일 CSS 433px의 가로 넘침 없음 확인. 비공개 값 대신 일치 여부만 기록했다.

## 운영 반영 전

실제 사업자 고지는 비공개 환경설정에만 있고 운영에는 아직 없다. 고객센터 전화와 통신판매업 신고번호 확인, 서비스 범위·제공자 사업자 여부·PG 정산 조건 확인이 남았다. 최종 PG 계약·결제 연동·재신청·운영 배포는 이 변경으로 완료되지 않는다.
